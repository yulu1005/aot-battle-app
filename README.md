# 進擊的巨人：角色對決進度條 App

##  專案主題：
進擊的巨人風格互動遊戲 App（使用 Android Studio）

##  應用內容：

本 App 是使用 CH7 與 CH8 完成的互動式應用，具備以下功能：

- 顯示角色與巨人對戰場景（含背景圖）
- 按「開始戰鬥」後，角色與巨人進行比賽（進度條逐步推進）
- 可透過「切換角色」選擇艾連、米卡莎或兵長，不同角色會有不同速度
- 對戰勝負結果以 Toast 提示顯示
- 使用者可反覆切換角色並重新挑戰

##  主要元件使用：

- `Button` 按鈕（開始戰鬥、切換角色）
- `TextView` 文字顯示（目前角色、對戰標題）
- `SeekBar` 作為角色與巨人進度條
- `Handler + Thread` 控制角色速度與動畫推進
- `ConstraintLayout` 結合背景圖與 UI 排版

##   使用資源：

- 背景圖：自製進擊風格插圖，設為 ConstraintLayout 背景
- 字體顏色與間距經設計優化，確保背景圖片下仍可清楚顯示文字

---

本專案可作為入門 Android UI 元件整合與動畫邏輯控制的練習。
